# Browser Compatibility

## Intended targets
- Chrome
- Microsoft Edge
- Firefox
- Safari
- Android Chrome
- iOS Safari

## Policy
1. Choose and document a minimum supported version during Phase 0.
2. Feature-detect APIs rather than relying only on user-agent strings.
3. Provide graceful fallbacks where practical.
4. Clearly identify optional features requiring newer APIs or WebGL.
5. Test reduced-motion behavior across supported browsers.
6. Record tested browser versions and known limitations.

Do not claim universal browser support merely because the engine uses JavaScript.
