# Effect Catalogue

This catalogue describes intended families, not a claim that they are already implemented. Mark each effect in FEATURE_STATUS.md as planned, in progress, complete, or deferred.

## Core 2D
- Translate X/Y
- Scale and rotate
- Skew
- Opacity
- Color/background color
- Border radius
- Supported dimensions and spacing
- CSS filter effects

## 3D
- Rotate X/Y/Z
- Translate Z
- Scale Z where meaningful
- Perspective
- Flip and card-like transitions
- Layered depth scenes

## Parallax
- Scroll progress
- Pointer movement
- Layered scene depth
- Direction and sensitivity controls
- Responsive and reduced-motion modes

## Transitions and reveals
- Fade
- Slide
- Zoom
- Wipe
- Clip-path reveal
- Mask reveal
- Blur in/out
- Staggered entrance/exit

## SVG
- Attribute animation
- Stroke drawing
- Transform animation
- Supported path-based effects

## Text
- Character, word, and line staggering
- Reveal and fade
- Directional movement
- Accessible text preservation

## Canvas and particles
- Particle emitters
- Basic shapes and sprites
- Motion trails where performant
- Optional Canvas renderer

## Motion and physics
- Spring-like motion
- Inertia
- Damped movement
- Follow/track behavior
- Bounds and constraints

## Image and background
- Pan/zoom
- Background position
- Layered image movement
- Supported mask/reveal transitions

## Advanced effects
- Distortion
- Displacement
- Morphing
- Shader/WebGL effects

Advanced effects must be clearly marked as optional and browser-dependent. Do not advertise an effect as supported until it is implemented, tested, and documented.
